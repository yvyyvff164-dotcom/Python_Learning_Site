Шартты операторлар

Бағдарламаға нәтижені шартқа қарай таңдауды үйретіңіз. if, elif, else тармақтарын ұпайлар мен кіру ережесі арқылы тексересіз.

Бағдарлама тармақты қалай таңдайды?

if бірінші шартты тексереді. Ол жалған болса, Python elif шартын қарайды. Ешбір шарт ақиқат болмаса, else тармағы орындалады. Тармақтардың ішінде шегініс қалдырыңыз және әр шарт жолын қос нүктемен аяқтаңыз.

Мысал: ұпайды санатқа бөлу

score = 76
if score >= 90:
    print("Өте жақсы")
elif score >= 70:
    print("Жақсы")
else:
    print("Тағы жаттығыңыз")

76 >= 90 шарты жалған, ал 76 >= 70 шарты ақиқат. Сондықтан экранға Жақсы шығады. 90-нан басталатын шарт бірінші тұруы қажет, өйткені 90 саны екі шартқа да сай келеді.

Салыстыру және логикалық амалдар

АмалМағынасыМысал
==, !=Тең, тең емесscore == 70
>, <Үлкен, кішіscore > 70
>=, <=Үлкен немесе тең, кіші немесе теңscore >= 70
and, orЕкі шарт та ақиқат, кемінде бір шарт ақиқатage >= 12 and has_ticket
notЛогикалық мәнді кері айналдырадыnot has_ticket

score = 70 мәнді меншіктейді. Ал score == 70 сол мәннің 70-ке теңдігін тексереді.

Шектегі мәндерді тексеріңіз

  1. score айнымалысына кезекпен 90, 70 және 69 мәндерін қойыңыз. Әр іске қосуда қай тармақ орындалатынын белгілеңіз.
  2. has_ticket мәнін False етіңіз. Жасы 12-ден асса да, кіруге бола ма?
  3. and сөзін or сөзіне ауыстырыңыз. Осы өзгеріс неліктен басқа нәтиже береді?

Ctrl / ⌘ + Enter — іске қосу. Tab — шегініс. Редактордан шығу үшін Esc, содан кейін Tab басыңыз.
