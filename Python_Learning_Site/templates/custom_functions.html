Өз функцияңызды жазыңыз

Тіктөртбұрыштың ауданын есептейтін функция анықтап, оны әртүрлі өлшемдермен шақырасыз. Есептеу бір жерде жазылады, ал нәтижені басқа есепте қолдануға болады.

Функцияның құрылымы

def — анықтау

Функцияның аты мен параметрлерін жақшаға жазыңыз. Жолды қос нүктемен аяқтап, денесін төрт бос орынға шегіндіріңіз.

Параметр және аргумент

eni мен uzyndygy — параметрлер. audan(3, 4) шақыруындағы 3 пен 4 — соларға берілетін аргументтер.

return — мән қайтару

Функцияны аяқтап, нәтижені оны шақырған жерге қайтарады. Қайтарылған мәнді айнымалыға сақтауға немесе есептеуге пайдалануға болады.

def audan(eni, uzyndygy):
    return eni * uzyndygy

birinshi = audan(3, 4)
ekinshi = audan(2, 5)
print(birinshi + ekinshi)  # 22

eni және uzyndygy тек функцияның ішінде қолданылады. Функциядан тыс жерде birinshi және ekinshi айнымалыларын пайдаланамыз.

Әдепкі мән

Параметрге бастапқы мән беруге болады. Мысалы, def darezhe(san, korsetkish=2) түріндегі функцияны тек бір аргументпен шақырсаңыз, екінші параметр 2-ге тең болады.

Өлшемдерді өзгертіп көріңіз

  1. Кодты іске қосып, екі ауданның қосындысы 22 екенін тексеріңіз.
  2. audan(5, 7) шақыруын қосыңыз. Шығатын мән 35 болуы керек.
  3. perimetr(eni, uzyndygy) функциясын жазып, 2 * (eni + uzyndygy) мәнін қайтарыңыз. perimetr(3, 4) үшін нәтиже 14.
  4. darezhe(4) және darezhe(4, 3) шақыруларының нәтижелерін салыстырыңыз.
