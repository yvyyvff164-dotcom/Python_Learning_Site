Жеңілдік калькуляторы

Дүкенде бір тауардың бірнеше данасын алғанда жеңілдіктен кейін қанша төлейсіз? Осы жобада тауардың жалпы бағасын, жеңілдік сомасын және соңғы төлемді есептейтін Python бағдарламасын құрастырасыз.

Калькулятор қалай жұмыс істейді?

Бағдарлама бір дананың бағасын, тауар санын және жеңілдік пайызын қабылдайды. Python тілінде input() енгізілген мәнді мәтін ретінде оқиды, ал int() оны бүтін санға айналдырады. if шарты 0–100 аралығындағы пайызды және оң мәндерді тексеруге көмектеседі.

  1. Бір дананың бағасын тауар санына көбейтіп, жалпы бағаны табыңыз.
  2. Жалпы бағаны жеңілдік пайызына көбейтіп, 100-ге бөліңіз.
  3. Жалпы бағадан жеңілдікті шегеріп, соңғы төлемді табыңыз.

Мысал

Данасы 1 200 ₸ тұратын 3 кітаптың жалпы бағасы 3 600 ₸. Жеңілдік 15% болса, 3 600 × 15 ÷ 100 = 540 ₸ шегеріледі. Соңғы төлем 3 060 ₸ болады.

Тексеру жағдайлары

Әр жағдайдағы соңғы төлемді ойша табыңыз, содан кейін мәндерді калькуляторға енгізіп, жауабыңызды салыстырыңыз.

  • Кәдімгі жеңілдік Бір дәптер 750 ₸ тұрады. 2 дәптерге 15% жеңілдік берілді. ✓ Тексерілді
  • Жеңілдік жоқ Бір қалам 320 ₸ тұрады. 4 қаламға жеңілдік 0%. ✓ Тексерілді
  • Толық жеңілдік Бір ашықхат 450 ₸ тұрады. 1 ашықхатқа жеңілдік 100%. ✓ Тексерілді
  • Қате мән Жеңілдікке 101% енгізіңіз. Калькулятор қандай хабарлама шығарады? ✓ Тексерілді

Python кодын құрастыру

Әр жолға сәйкес өрнекті таңдаңыз. Содан кейін бағдарламаны Python редакторында жазып, жоғарыдағы мәндермен тексеріңіз.

Python бағдарламасының үлгісін ашу 
try:
    баға = int(input("Бір дананың бағасы, теңге: "))
    саны = int(input("Тауар саны: "))
    пайыз = int(input("Жеңілдік пайызы: "))

    if 1 <= баға <= 1_000_000 and 1 <= саны <= 100 and 0 <= пайыз <= 100:
        жалпы_баға = баға * саны
        жеңілдік = жалпы_баға * пайыз / 100
        төлем = жалпы_баға - жеңілдік

        print(f"Жалпы баға: {жалпы_баға:.2f} ₸")
        print(f"Жеңілдік сомасы: {жеңілдік:.2f} ₸")
        print(f"Соңғы төлем: {төлем:.2f} ₸")
    else:
        print("Баға, сан немесе пайыз рұқсат етілген аралықтан тыс.")
except ValueError:
    print("Барлық мәнді бүтін санмен енгізіңіз.")
