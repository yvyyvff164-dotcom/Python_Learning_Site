🧭 Блок-схема құрастырушы (FlowRun)

Блок-схема — алгоритмді фигуралар мен көрсеткілер арқылы көрсететін сурет. Өткен жылы біз есепті шешу алдында блок-схема құруды үйрендік. Төмендегі құрастырушыда фигураларды сүйреп қойып, олардан алгоритм жинайсың, ал сайт сол схеманы Python кодына автоматты түрде айналдырады және оны бірден іске қосады.

🔗 Түпнұсқа FlowRun бағдарламасын ашу

🧱 Блоктар (фигуралар)

Басы / Соңы

Сопақ фигура. Алгоритм осыдан басталып, осымен аяқталады. Ол әрқашан тұрады.

Енгізу

Параллелограмм. Пайдаланушыдан мән сұрайды: a = int(input()).

Шығару

Параллелограмм. Нәтижені экранға шығарады: print(...).

Есептеу

Тіктөртбұрыш. Айнымалыға мән береді немесе есептейді: s = a + b.

Шарт

Ромб. Сұрақ қояды. Иә және Жоқ тармақтары бөлек орындалады: if ... else.

Цикл (while / for)

Алтыбұрыш. Ішіндегі блоктарды қайталайды: while шарт орындалғанша, for белгілі рет.

🛠 Өзің құрастыр

Қалай жұмыс істейді: сол жақтағы блокты схемаға сүйреп апар (немесе блокты бір рет басып, содан кейін схемадағы ＋ орынды бас — бұл телефонда ыңғайлы). Блоктың ішіндегі өрістерге мәнін жаз. Код төменде автоматты түрде жаңарады.
