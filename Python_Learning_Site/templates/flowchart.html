Блок-схема құрастыру

Фигуралардан алгоритм құрастырып, оның Python кодын оқисыз және нәтижесін тексересіз. Блоктар әрекеттерді, ал көрсеткілер олардың орындалу ретін көрсетеді.

Екі санды қалай қосамыз?

Әуелі екі бүтін сан енгіземіз. Оларды a және b айнымалыларына сақтаймыз. Келесі блок a + b мәнін есептейді, ал соңғы блок қосындыны экранға шығарады.

Басы → Енгізу → Енгізу → Есептеу → Шығару → Соңы

a = int(input("Бірінші сан: "))
b = int(input("Екінші сан: "))
s = a + b
print("Қосындысы:", s)

Үлгіні төмендегі тізімнен таңдап, 2 және 3 сандарын енгізіңіз. Экранға Қосындысы: 5 шығады.

Блоктардың қызметі

Басы / Соңы

Сопақ фигура. Алгоритм осыдан басталып, осымен аяқталады. Ол әрқашан тұрады.

Енгізу

Параллелограмм пайдаланушыдан мән сұрайды. Мысалы, a = int(input()).

Шығару

Параллелограмм нәтижені экранға шығарады. Мысалы, print(...).

Есептеу

Тіктөртбұрыш есептейді немесе айнымалыға мән береді. Мысалы, s = a + b.

Шарт

Ромб шартты тексереді. Нәтижеге қарай Иә немесе Жоқ тармағы орындалады.

Цикл (while / for)

Алтыбұрыш ішіндегі блоктарды қайталайды. while шарты ақиқат болған кезде жалғасады. for тізбектегі әр мән үшін бір рет орындалады.

Схеманы құрастырыңыз

Блокты схемаға сүйреп апарыңыз немесе әуелі блокты, содан кейін ＋ орнын басыңыз. Пернетақтамен блокты Enter арқылы таңдаңыз, қажетті орынға Tab арқылы өтіп, Enter басыңыз. Өрісті өзгерткенде Python коды бірден жаңарады.
