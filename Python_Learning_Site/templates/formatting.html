✨ Форматтау (f-strings)

Мәтін ішіне айнымалылардың мәнін қою үшін Python-да ең ыңғайлы тәсіл — f-string (formatted string). Жолдың алдына f әрпін жазасыз, ал айнымалыны фигуралы жақшаның ішіне қоясыз. 

at = "Aruzhan"
print(f"Сәлем, {at}!")   # Сәлем, Aruzhan!

🛠 f-string мүмкіндіктері

1. Айнымалыны қою

{at} — айнымалының мәні жолдың ішіне автоматты түрде қойылады.

2. Есептеулер

Жақшаның ішінде өрнек жазуға болады: {a + b}, {a * b}.

3. Сандарды форматтау

Қос нүктеден кейін формат жазылады: {baga:.2f} — үтірден кейін 2 таңба.

📊 Жиі қолданылатын форматтар

Формат Мағынасы Мысал
:.2f Ондық санның үтірден кейінгі 2 таңбасы f"{3.14159:.2f}" → 3.14
:03d Бүтін санды нөлмен 3 таңбаға толтыру f"{7:03d}" → 007
:<10 Солға туралау (10 таңба ені) f"{'a':<5}|" → a    |
:>10 Оңға туралау (10 таңба ені) f"{'a':>5}|" →     a|
:^10 Ортаға туралау (10 таңба ені) f"{'a':^5}|" →   a  |

⚠️ Жиі кездесетін қателер

1. f әрпін ұмытып кету

"Сәлем, {at}" деп жазсаң, Python айнымалыны қоймайды, жақшаның өзін шығарады. Жолдың алдына f қою керек.

2. Тырнақшаның шатасуы

Жолдың сыртында қос тырнақша болса, ішінде бір тырнақша қолдан (және керісінше), әйтпесе синтаксистік қате шығады.
