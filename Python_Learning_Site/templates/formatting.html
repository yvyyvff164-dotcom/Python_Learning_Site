Мәтінді пішімдеу (f-string)

f-string айнымалының мәнін немесе есептің нәтижесін мәтінге кірістіреді. Жолдың алдына f әрпін қойып, кірістірілетін өрнекті { } жақшасына жазыңыз.

▸ Бейнесабақты көру 
at = "Aruzhan"
print(f"Сәлем, {at}!")   # Сәлем, Aruzhan!

f-string арқылы не істеуге болады?

1. Айнымалыны қою

{at} — айнымалының мәні жолдың ішіне автоматты түрде қойылады.

2. Есептеулер

Жақшаның ішінде өрнек жазуға болады: {a + b}, {a * b}.

3. Сандарды форматтау

Қос нүктеден кейін формат жазылады: {baga:.2f} — ондық нүктеден кейін 2 таңба.

Пішімдеу үлгілері

Формат Мағынасы Мысал
:.2f Ондық нүктеден кейінгі 2 таңба f"{3.14159:.2f}" → 3.14
:03d Бүтін санды нөлмен 3 таңбаға толтыру f"{7:03d}" → 007
:<5 Солға туралау (5 таңбалық өріс) f"{'a':<5}|" → a    |
:>5 Оңға туралау (5 таңбалық өріс) f"{'a':>5}|" →     a|
:^5 Ортаға туралау (5 таңбалық өріс) f"{'a':^5}|" →   a  |

Мысал. Жалпы бағаны көрсету

Алдымен жақша ішіндегі 2 * 49.5 өрнегі есептеледі. Содан кейін :.2f нәтижені ондық нүктеден кейін екі таңбамен көрсетеді.

print(f"Жалпы баға: {2 * 49.5:.2f} тг")
# Жалпы баға: 99.00 тг

Практика

Тапсырыс туралы хабарлама жасау

  1. Редактордың соңына quantity = 3 және price = 149.9 айнымалыларын қосыңыз.
  2. f-string ішінде тауар санын көрсетіп, жалпы бағасын есептеңіз. Бағаны ондық нүктеден кейін екі таңбамен шығарыңыз.

Күтілетін нәтиже 3 дана — 449.70 тг

Пернетақтамен іске қосу үшін Ctrl + Enter немесе ⌘ + Enter басыңыз.

▸ Шешім үлгісін көру 
quantity = 3
price = 149.9
print(f"{quantity} дана — {quantity * price:.2f} тг")

⚠️ Жиі кездесетін қателер

1. f әрпін ұмытып кету

"Сәлем, {at}" деп жазсаң, Python айнымалыны қоймайды, жақшаның өзін шығарады. Жолдың алдына f қою керек.

2. Тырнақшаның шатасуы

Редакторда f-string үшін қос тырнақша, ішіндегі жол үшін бір тырнақша қолдануға болады. Мысалы, f"{'алма'.upper()}".
