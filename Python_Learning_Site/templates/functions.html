🧩 Python-дағы функциялар және 30 негізгі әдіс

Функция — бұл белгілі бір логикалық тапсырманы орындайтын және қажет кезде қайта-қайта шақыруға болатын дербес код блогы. Python тілінде функциялар бағдарламаны модульдік бөліктерге бөліп, кодымызды таза, түсінікті әрі қайталанатын қателерден арылтуға мүмкіндік береді.

⚙️ Өз функциямызды қалай жасаймыз? (Custom Functions)

Python тілінде жаңа функция құру үшін міндетті түрде def түйінді сөзі қолданылады. Оның артынан функция аты және жақша ішінде аргументтер (параметрлер) көрсетіледі.

# Функцияны анықтау
def salemdesu(at):
    return "Сәлем, " + at + "! Python әлеміне қош келдің."

# Функцияны шақыру
nateje = salemdesu("Санжар")
print(nateje)  # Нәтиже: Сәлем, Санжар! Python әлеміне қош келдің.

return операторы функцияның жұмыс нәтижесін сыртқа қайтару үшін қолданылады. Егер return көрсетілмесе, функция әдепкі бойынша None мәнін қайтарады.

📚 Толық анықтама: Python-дағы ең маңызды 30 кірістірілген функция

Төменде кез келген бағдарламашы білуге тиіс ең көп қолданылатын 30 кірістірілген (built-in) функция жинақталған:

1. print()

Мәліметтерді консольге шығарады.

print("Hello, World!")
2. input()

Пайдаланушыдан мәтін енгізуді сұрайды.

at = input("Атыңыз кім?")
3. len()

Жол немесе тізім ұзындығын қайтарады.

len([1, 2, 3, 4])  # 4
4. type()

Деректер типін анықтайды.

type(15)  # <class 'int'>
5. int()

Мәнді бүтін санға түрлендіреді.

int("100")  # 100
6. float()

Мәнді ондық санға айналдырады.

float("3.14")  # 3.14
7. str()

Мәнді жол (мәтін) форматына өткізеді.

str(45)  # "45"
8. list()

Басқа құрылымды тізімге айналдырады.

list("abc")  # ['a', 'b', 'c']
9. tuple()

Өзгермейтін кортеж жасайды.

tuple([1, 2])  # (1, 2)
10. dict()

Сөздік (dictionary) құрады.

dict(a=1, b=2)
11. set()

Қайталанбайтын элементтер жиыны.

set([1, 2, 2, 3])  # {1, 2, 3}
12. range()

Сандар тізбегін генерациялайды.

list(range(1, 5))  # [1, 2, 3, 4]
13. sum()

Сандардың қосындысын есептейді.

sum([10, 20, 30])  # 60
14. max()

Ең үлкен элементті табады.

max([5, 9, 2])  # 9
15. min()

Ең кіші элементті табады.

min([5, 9, 2])  # 2
16. abs()

Санның модулін қайтарады.

abs(-15)  # 15
17. round()

Санды дөңгелектейді.

round(3.78)  # 4
18. pow()

Санды дәрежеге көтереді.

pow(2, 3)  # 8
19. sorted()

Тізімді реттеп шығарады.

sorted([3, 1, 2])  # [1, 2, 3]
20. reversed()

Тізімді кері бұрады.

list(reversed([1, 2, 3]))  # [3, 2, 1]
21. enumerate()

Индекс пен мәнді қатар береді.

list(enumerate(['a', 'b']))
22. zip()

Тізімдерді жұптастырады.

list(zip([1, 2], ['a', 'b']))
23. map()

Әр элементке функция қолданады.

list(map(int, ["1", "2"]))
24. filter()

Шарт бойынша іріктейді.

list(filter(None, [0, 1, 5]))
25. all()

Барлығы шын болса True береді.

all([True, True])  # True
26. any()

Біреуі шын болса True береді.

any([False, True])  # True
27. chr()

Unicode символын қайтарады.

chr(65)  # 'A'
28. ord()

Символ кодын анықтайды.

ord('A')  # 65
29. dir()

Объект әдістерін тізімдейді.

dir(list)
30. help()

Анықтамалық құжаттама шақырады.

help(print)
