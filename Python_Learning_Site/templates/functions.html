Python-ның кірістірілген функциялары

Бағалар тізіміндегі мәндерді санап, ең жоғары бағаны және орташа мәнді табасыз. Бұл есептерге Python-ның дайын len(), max() және sum() функцияларын қолданамыз.

Дайын функцияны қалай шақырамыз?

Функция бір әрекетті орындайды. Оны шақыру үшін атауынан кейін жақша жазып, оған қажет мәнді — аргументті — береміз. Мысалы, sum(bagalar) тізімдегі сандардың қосындысын қайтарады. Сол қосындыны тізім ұзындығына бөлсек, орташа баға шығады.

bagalar = [70, 85, 90, 75]
sany = len(bagalar)
orta = sum(bagalar) / sany

print(sany)           # 4
print(max(bagalar))   # 90
print(orta)           # 80.0

print() мәнді экранға шығарады. max() ең үлкен мәнді қайтарады, сондықтан оны айнымалыға сақтауға немесе бірден print() ішіне жазуға болады.

Бағалар тізімін талдаңыз

  1. Кодты іске қосып, орташа бағаның 80.0 екенін тексеріңіз.
  2. Тізімге 100 қосыңыз. Енді тізімде 5 баға бар және орташа мән 84.0 шығады.
  3. min() арқылы ең төмен бағаны шығарыңыз. Осы тізім үшін нәтиже 70 болуы керек.

30 кірістірілген функция

Қажетті топты ашып, функцияның не қайтаратынын және оның қалай шақырылатынын қараңыз.

▸ Енгізу, шығару және түрлендіру
print()

Мәліметтерді консольге шығарады.

print("Сәлем, әлем!")
input()

Пайдаланушыдан мәтін енгізуді сұрайды.

at = input("Атыңыз кім?")
len()

Жол немесе тізім ұзындығын қайтарады.

len([1, 2, 3, 4])  # 4
type()

Мәннің дерек түрін қайтарады.

type(15)  # <class 'int'>
int()

Мәнді бүтін санға түрлендіреді.

int("100")  # 100
float()

Мәнді ондық санға айналдырады.

float("3.14")  # 3.14
str()

Мәнді жол (мәтін) форматына өткізеді.

str(45)  # "45"
list()

Басқа құрылымды тізімге айналдырады.

list("abc")  # ['a', 'b', 'c']
tuple()

Өзгермейтін кортеж жасайды.

tuple([1, 2])  # (1, 2)
dict()

Сөздік (dictionary) құрады.

dict(a=1, b=2)
set()

Қайталанбайтын элементтер жиыны.

set([1, 2, 2, 3])  # {1, 2, 3}
range()

Сандар тізбегін генерациялайды.

list(range(1, 5))  # [1, 2, 3, 4]
▸ Есептеу және реттеу
sum()

Сандардың қосындысын есептейді.

sum([10, 20, 30])  # 60
max()

Ең үлкен элементті табады.

max([5, 9, 2])  # 9
min()

Ең кіші элементті табады.

min([5, 9, 2])  # 2
abs()

Санның модулін қайтарады.

abs(-15)  # 15
round()

Санды дөңгелектейді.

round(3.78)  # 4
pow()

Санды дәрежеге көтереді.

pow(2, 3)  # 8
sorted()

Элементтерден сұрыпталған жаңа тізім жасайды.

sorted([3, 1, 2])  # [1, 2, 3]
reversed()

Элементтерді соңынан басына қарай береді.

list(reversed([1, 2, 3]))  # [3, 2, 1]
▸ Тізбектермен жұмыс
enumerate()

Индекс пен мәнді қатар береді.

list(enumerate(['a', 'b']))
zip()

Тізімдерді жұптастырады.

list(zip([1, 2], ['a', 'b']))
map()

Әр элементке функция қолданады.

list(map(int, ["1", "2"]))
filter()

Тексеру нәтижесі шын болатын элементтерді қалдырады.

list(filter(None, [0, 1, 5]))
all()

Барлығы шын болса True береді.

all([True, True])  # True
any()

Кемінде бір мән шын болса, True қайтарады.

any([False, True])  # True
▸ Таңбалар және анықтама
chr()

Unicode символын қайтарады.

chr(65)  # 'A'
ord()

Символ кодын анықтайды.

ord('A')  # 65
dir()

Нысандағы атаулар мен әдістердің тізімін қайтарады.

dir(list)
help()

Python-ның анықтамасын ашады. Оны жергілікті Python ортасында іске қосыңыз.

help(print)
