Циклдер

for және while арқылы әрекетті қайталаңыз. Сандар қатарын құрып, тізім элементтерін аралап, кері санақ жасайсыз.

Қайталауды қалай жазамыз?

Цикл шегініспен жазылған код блогын қайталайды. for тізім немесе range() сияқты берілген мәндерді аралайды. while әр айналым алдында шартты тексереді.

for — мәндерді ретімен алу

for number in range(1, 4):
    print(number)

range(1, 4) ретімен 1, 2, 3 мәндерін береді. Соңғы шек 4 бұл қатарға кірмейді.

while — шарт ақиқат болғанша қайталау

number = 1
while number < 4:
    print(number)
    number += 1

number әр айналымда өседі. Ол 4 болғанда шарт жалған болып, цикл тоқтайды.

Екі мысал да сандарды жеке жолдарға шығарады. Әр циклдің бірінші жолы қос нүктемен аяқталады. while ішінде санды жаңартуды ұмытсаңыз, шарт ақиқат күйінде қалып, цикл тоқтамауы мүмкін.

Сандарды шығарып, кері санаңыз

  1. Бастапқы кодты іске қосыңыз. Кері санақ 0-ді неге шығармайтынын анықтаңыз.
  2. Бірінші for циклін 2-ден 20-ға дейінгі жұп сандарды шығаратындай өзгертіңіз. range() үшінші параметрі ретінде 2 қадамын қолданыңыз.
  3. while циклінде 10-нан бастап 1-ге дейін кері санаңыз. Шарт пен санды азайтатын жолдың қалай жұмыс істейтінін түсіндіріңіз.

Ctrl / ⌘ + Enter — іске қосу. Tab — шегініс. Редактордан шығу үшін Esc, содан кейін Tab басыңыз.

▸ Мүмкін шешімді көру 
for number in range(2, 21, 2):
    print(number)

remaining = 10
while remaining > 0:
    print(remaining)
    remaining -= 1

Бірінші нәтиже 2-ден басталып, 20-мен аяқталады. Екіншісі 10-нан 1-ге дейін кемиді. remaining 0 болғанда while шарты жалған.
