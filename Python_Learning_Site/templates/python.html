Python деген не?

Python көмегімен компьютерге нұсқау беріп, алғашқы бағдарламаңыздың нәтижесін браузерде көресіз.

Python коды қалай жұмыс істейді?

Бағдарлама — компьютер орындайтын нұсқаулар жиыны. Төмендегі қарапайым бағдарламада екі нұсқау бар. Python оларды жоғарыдан төмен қарай орындайды.

Код

print("Сәлем, әлем!")
print(3 + 4)

Нәтиже

Сәлем, әлем!
7

Бірінші print() тырнақша ішіндегі мәтінді шығарады. Екінші жолда Python алдымен 3 + 4 өрнегін есептеп, содан кейін нәтижесін шығарады.

Алғашқы бағдарламаңызды іске қосыңыз

  1. Кодты іске қосу батырмасын басып, нәтижені қараңыз.
  2. Екінші жолдағы мәтіннің орнына өз атыңызды жазыңыз. Тырнақшаларды сақтаңыз.
  3. Есептеу мысалын таңдаңыз. Сандарды өзгертіп, жаңа нәтиженің қандай болатынын болжап көріңіз.

Ctrl / ⌘ + Enter — іске қосу. Tab — шегініс. Редактордан шығу үшін Esc, содан кейін Tab басыңыз.

Python не үшін қолданылады?

Деректерді талдау

Кестеден дерек оқып, орташа мәнді есептеуге және график салуға болады.

Автоматтандыру

Бірнеше файлдың атауын ауыстыру сияқты қайталанатын жұмысты кодқа тапсыра аласыз.

Веб-қосымшалар

Python веб-серверге сұраныстарды өңдеуге және бетке дерек ұсынуға көмектеседі.

▸ Python тілінің қысқаша тарихы

Тілді Гвидо ван Россум жасады. Алғашқы нұсқасы 1991 жылы шықты. Атауы британдық Monty Python әзіл-сықақ тобына байланысты. Бұл курста Python 3 синтаксисін қолданасыз.

▸ Браузердегі редакторды қалай қолданамын?

Кодты осы бетте іске қосу үшін компьютерге Python орнатудың қажеті жоқ. Қате шықса, алдымен хабарламада көрсетілген жолды тексеріңіз. Мысалы, жабылмаған тырнақшаны немесе жақшаны іздеңіз.
