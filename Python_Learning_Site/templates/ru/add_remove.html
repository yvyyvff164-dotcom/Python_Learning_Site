Добавление и удаление элементов списка

Список можно пополнять и сокращать. На этом уроке вы научитесь выбирать метод в зависимости от того, известна ли вам позиция элемента или его значение.

▸ Посмотреть видеоурок

Методы для работы со списком

Добавление элементов

  • append(x) — добавляет элемент в конец списка.
  • insert(i, x) вставляет x перед элементом с индексом i.

Удаление элементов

  • remove(x) — удаляет первый элемент со значением x.
  • pop(i) удаляет элемент с индексом i и возвращает его значение. Вызов pop() без индекса извлекает последний элемент.

Пример. Как удалить повторяющееся значение

remove("Яблоко") удаляет первое в списке яблоко. pop(0) извлекает первый элемент списка и позволяет сохранить его в переменную.

fruits = ["Яблоко", "Груша", "Яблоко"]
fruits.remove("Яблоко")
print(fruits)  # ['Груша', 'Яблоко']
removed = fruits.pop(0)
print(removed)  # Груша
