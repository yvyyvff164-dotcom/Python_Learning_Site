Одномерный массив в Python — список

Список (list) хранит значения в заданном порядке. На этом уроке вы научитесь находить элемент по индексу и заменять его новым значением.

▸ Посмотреть видеоурок

Как найти индекс элемента

У каждого элемента списка есть свой номер — индекс. Нумерация начинается с нуля!

Индекс от начала (0, 1, 2...)

Считайте слева направо. Индекс первого элемента — [0].

Отрицательный индекс (-1, -2...)

Считайте с конца списка. Индекс последнего элемента — [-1].

Пример. Два индекса одного элемента

fruits[1] и fruits[-3] указывают на один и тот же фрукт. В первом случае отсчёт идёт от начала, во втором — от конца списка.

ФруктЯблокоГрушаБананВишня
Индекс от начала0123
Отрицательный индекс−4−3−2−1
 
fruits = ["Яблоко", "Груша", "Банан", "Вишня"]
print(fruits[1], fruits[-3])  # Груша Груша

Практика

Обновите список фруктов

  1. Запустите пример и определите индекс второго фрукта.
  2. В конце программы замените второй фрукт на "Абрикос". Выведите обновлённый список, а на следующей строке — последний фрукт.

Ожидаемый результат ['Яблоко', 'Абрикос', 'Дыня', 'Вишня'], на следующей строке — Вишня

Чтобы запустить код с клавиатуры, нажмите Ctrl + Enter или ⌘ + Enter.

⚠️ Частая ошибка:

Если обратиться к индексу за пределами списка, Python выдаст ошибку IndexError. Например, нельзя получить десятый элемент списка, в котором всего три элемента.
