Координаты и циклы

В этом проекте вы спланируете сад на сетке 5 × 5. Выберите клетки для пруда, деревьев и скамеек, а затем опишите их положение в программе на Python с помощью координат и циклов.

Как построить план?

1. Прочитайте координаты

Положение клетки задаёт пара (x, y). Клетка (0, 0) находится в левом нижнем углу. Отсюда отсчитывайте шаги вправо по оси x и вверх по оси y. Например, чтобы попасть в (2, 1), пройдите две клетки вправо и одну вверх.

2. Вычислите новое положение

При движении вправо x увеличивается, влево — уменьшается. При движении вверх увеличивается y, вниз — уменьшается. Например, если из (2, 2) пройти одну клетку вправо и две вниз, вы окажетесь в (3, 0).

x, y = (2, 2)
новая_позиция = (x + 1, y - 2)
print(новая_позиция)

3. Постройте ряд с помощью цикла

В одном горизонтальном ряду у всех клеток одинаковый y. В цикле с range(0, 3) переменная x по очереди принимает значения 0, 1 и 2. Программа добавляет в список точки (0, 2), (1, 2) и (2, 2).

точки = []
for x in range(0, 3):
    точки.append((x, 2))
print(точки)
