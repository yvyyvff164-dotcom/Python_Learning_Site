Как написать свою функцию

Вы напишете функцию для вычисления площади прямоугольника и вызовете её для разных размеров. Формула будет записана один раз, а результат можно будет использовать в других вычислениях.

Из чего состоит функция

def — определение функции

После def укажите имя функции, а в круглых скобках перечислите параметры. Закончите строку двоеточием. Команды в теле функции пишите с отступом в четыре пробела.

Параметры и аргументы

eni и uzyndygy — параметры, ширина и длина. При вызове audan(3, 4) вместо них подставляются аргументы 3 и 4.

return — возврат значения

Завершает выполнение функции и возвращает результат в то место программы, где её вызвали. Это значение можно сохранить в переменной или сразу использовать в вычислении.

def audan(eni, uzyndygy):
    return eni * uzyndygy

birinshi = audan(3, 4)
ekinshi = audan(2, 5)
print(birinshi + ekinshi)  # 22

Параметры eni и uzyndygy доступны только внутри функции. Снаружи мы сохраняем результаты в переменных birinshi и ekinshi.

Значение по умолчанию

Параметру можно задать значение по умолчанию. Например, если вызвать функцию def darezhe(san, korsetkish=2) с одним аргументом, второй параметр примет значение 2.

Измените размеры прямоугольника

  1. Запустите код и проверьте, что сумма двух площадей равна 22.
  2. Добавьте вызов audan(5, 7) и выведите результат. Должно получиться 35.
  3. Напишите функцию perimetr(eni, uzyndygy), которая возвращает 2 * (eni + uzyndygy). Проверьте себя: perimetr(3, 4) должен вернуть 14.
  4. Сравните результаты вызовов darezhe(4) и darezhe(4, 3).

Ctrl + Enter или ⌘ + Enter — запуск. Tab — отступ в четыре пробела. Чтобы выйти из редактора, нажмите Esc, затем Tab.
