Калькулятор скидок

Сколько придётся заплатить за несколько одинаковых товаров с учётом скидки? В этом проекте вы напишете программу на Python, которая рассчитает стоимость покупки, размер скидки в тенге и итоговую сумму.

Попробовать калькулятор ↓

Как работает калькулятор?

На вход программа получает цену одного товара, количество и процент скидки. Функция input() читает введённое значение как текст, а int() преобразует его в целое число. С помощью условия if можно проверить, что цена и количество положительны, а скидка лежит в пределах от 0 до 100 процентов.

  1. Умножьте цену одного товара на количество, чтобы узнать стоимость покупки до скидки.
  2. Умножьте стоимость покупки на процент скидки и разделите на 100.
  3. Вычтите сумму скидки из стоимости покупки. Получится сумма к оплате.

Пример

Три книги по 1 200 ₸ стоят 3 600 ₸. При скидке 15% покупка обойдётся на 3 600 × 15 ÷ 100 = 540 ₸ дешевле. К оплате останется 3 060 ₸.

Соберите программу на Python

Выберите выражение для каждой строки. Затем запишите программу в редакторе Python и проверьте её на примерах выше.

Показать пример программы на Python 
try:
    цена = int(input("Цена одного товара в тенге: "))
    количество = int(input("Количество товаров: "))
    процент = int(input("Процент скидки: "))

    if 1 <= цена <= 1_000_000 and 1 <= количество <= 100 and 0 <= процент <= 100:
        стоимость = цена * количество
        скидка = стоимость * процент / 100
        итог = стоимость - скидка

        print(f"Стоимость до скидки: {стоимость:.2f} ₸")
        print(f"Сумма скидки: {скидка:.2f} ₸")
        print(f"К оплате: {итог:.2f} ₸")
    else:
        print("Цена, количество или процент скидки выходят за допустимые пределы.")
except ValueError:
    print("Введите целое число в каждом поле.")
