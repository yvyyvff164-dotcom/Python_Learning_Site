Конструктор блок-схем

Вы соберёте алгоритм из фигур, посмотрите, какой код на Python им соответствует, и проверите результат. Блоки обозначают действия, а стрелки задают порядок их выполнения.

Как сложить два числа?

Сначала вводим два целых числа и сохраняем их в переменных a и b. Следующий блок вычисляет a + b, а последний выводит сумму на экран.

Начало → Ввод → Ввод → Вычисления → Вывод → Конец

a = int(input("Первое число: "))
b = int(input("Второе число: "))
s = a + b
print("Сумма:", s)

Выберите пример сложения в списке ниже. Введите по очереди 2 и 3. На экране появится Сумма: 5.

Что обозначают блоки

Начало / Конец

Овалы отмечают начало и конец алгоритма. Они всегда присутствуют на схеме.

Ввод

Параллелограмм ввода запрашивает значение у пользователя. Например, a = int(input()).

Вывод

Параллелограмм вывода показывает результат на экране. Например, print(...).

Вычисления

Прямоугольник обозначает вычисление или присваивание значения переменной. Например, s = a + b.

Условие

В ромбе проверяется условие. В зависимости от результата выполняется ветка Да или Нет.

Цикл (while / for)

Шестиугольник обозначает цикл. while повторяет блоки, пока условие истинно. for выполняет их для каждого значения последовательности.

Соберите блок-схему

Перетащите блок на схему или щёлкните по нему, а затем по кнопке ＋ в месте вставки. С клавиатуры выберите блок клавишей Enter, перейдите к нужному месту клавишей Tab и снова нажмите Enter. Когда вы меняете поля блока, код Python обновляется сразу.
