Форматирование строк (f-string)

С помощью f-строки можно вставить в текст значение переменной или результат вычисления. Поставьте f перед кавычками и запишите выражение в фигурных скобках { }.

▸ Посмотреть видеоурок 
name = "Аружан"
print(f"Привет, {name}!")   # Привет, Аружан!

Что можно сделать с помощью f-строки?

1. Подстановка переменной

{name} — на месте этого выражения появится значение переменной.

2. Вычисления

В фигурных скобках можно записать выражение, например: {a + b}, {a * b}.

3. Форматирование чисел

После двоеточия укажите формат. Например, {price:.2f} выводит число с двумя знаками после десятичной точки.

Примеры форматов

Формат Значение Пример
:.2f Два знака после десятичной точки f"{3.14159:.2f}" → 3.14
:03d Целое число из трёх или более знаков с нулями слева f"{7:03d}" → 007
:<5 Выравнивание влево (поле шириной 5 символов) f"{'a':<5}|" → a    |
:>5 Выравнивание вправо (поле шириной 5 символов) f"{'a':>5}|" →     a|
:^5 Выравнивание по центру (поле шириной 5 символов) f"{'a':^5}|" →   a  |

Пример. Вывод стоимости покупки

Сначала Python вычислит выражение 2 * 49.5 в фигурных скобках. Затем формат :.2f выведет результат с двумя знаками после десятичной точки.

print(f"Стоимость: {2 * 49.5:.2f} тг")
# Стоимость: 99.00 тг

Практика

Составьте сообщение о заказе

  1. В конце программы задайте переменные quantity = 3 и price = 149.9.
  2. В f-строке укажите количество товаров и вычислите общую стоимость. Выведите стоимость с двумя знаками после десятичной точки.

Ожидаемый результат 3 шт. — 449.70 тг

Чтобы запустить код с клавиатуры, нажмите Ctrl + Enter или ⌘ + Enter.

⚠️ Частые ошибки

1. Пропущена буква f

"Привет, {name}" выведет фигурные скобки и имя переменной как обычный текст. Чтобы подставить значение переменной, добавьте перед строкой f.

2. Кавычки внутри f-строки

Если сама f-строка заключена в двойные кавычки, строку внутри выражения можно взять в одинарные. Например, f"{'яблоко'.upper()}".
