Встроенные функции Python

Вы узнаете, сколько оценок в списке, найдёте высшую оценку и средний балл. Для этого в Python уже есть функции len(), max() и sum().

Как вызвать встроенную функцию?

Чтобы вызвать функцию, напишите её имя и круглые скобки. В скобках передайте нужное значение — аргумент. Например, sum(bagalar) возвращает сумму чисел в списке. Если разделить её на длину списка, получится средний балл.

bagalar = [70, 85, 90, 75]
sany = len(bagalar)
orta = sum(bagalar) / sany

print(sany)           # 4
print(max(bagalar))   # 90
print(orta)           # 80.0

print() выводит значение на экран. max() возвращает наибольшее значение: его можно сохранить в переменной или сразу передать в print().

Разберите список оценок

  1. Запустите код и убедитесь, что средний балл равен 80.0.
  2. Добавьте в список 100. Теперь в нём пять оценок, а средний балл равен 84.0.
  3. Выведите наименьшую оценку с помощью min(). Для этого списка должно получиться 70.

Ctrl + Enter или ⌘ + Enter — запуск. Tab — отступ в четыре пробела. Чтобы выйти из редактора, нажмите Esc, затем Tab.

30 встроенных функций

Откройте нужную группу, чтобы посмотреть, как вызвать функцию и какое значение она вернёт.

▸ Ввод, вывод и преобразование типов
print()

Выводит данные в консоль.

print("Привет, мир!")
input()

Запрашивает ввод и возвращает введённый текст.

at = input("Как вас зовут?")
len()

Возвращает длину строки или списка.

len([1, 2, 3, 4])  # 4
type()

Возвращает тип значения.

type(15)  # <class 'int'>
int()

Преобразует значение в целое число.

int("100")  # 100
float()

Преобразует значение в число с плавающей точкой.

float("3.14")  # 3.14
str()

Преобразует значение в строку.

str(45)  # "45"
list()

Создаёт список из элементов переданного объекта.

list("abc")  # ['a', 'b', 'c']
tuple()

Создаёт кортеж — неизменяемую последовательность.

tuple([1, 2])  # (1, 2)
dict()

Создаёт словарь.

dict(a=1, b=2)
set()

Создаёт множество уникальных элементов.

set([1, 2, 2, 3])  # {1, 2, 3}
range()

Задаёт диапазон целых чисел.

list(range(1, 5))  # [1, 2, 3, 4]
▸ Вычисления и порядок элементов
sum()

Вычисляет сумму чисел.

sum([10, 20, 30])  # 60
max()

Находит наибольший элемент.

max([5, 9, 2])  # 9
min()

Находит наименьший элемент.

min([5, 9, 2])  # 2
abs()

Возвращает модуль числа.

abs(-15)  # 15
round()

Округляет число.

round(3.78)  # 4
pow()

Возводит число в степень.

pow(2, 3)  # 8
sorted()

Создаёт новый отсортированный список.

sorted([3, 1, 2])  # [1, 2, 3]
reversed()

Позволяет перебрать элементы в обратном порядке.

list(reversed([1, 2, 3]))  # [3, 2, 1]
▸ Работа с последовательностями
enumerate()

При переборе возвращает индекс вместе со значением.

list(enumerate(['a', 'b']))
zip()

Объединяет элементы списков попарно.

list(zip([1, 2], ['a', 'b']))
map()

Применяет функцию к каждому элементу.

list(map(int, ["1", "2"]))
filter()

Оставляет элементы, которые проходят проверку.

list(filter(None, [0, 1, 5]))
all()

Возвращает True, если все значения истинны.

all([True, True])  # True
any()

Возвращает True, если хотя бы одно значение истинно.

any([False, True])  # True
▸ Символы и справка
chr()

Возвращает символ Unicode по его коду.

chr(65)  # 'A'
ord()

Возвращает числовой код символа.

ord('A')  # 65
dir()

Возвращает список имён атрибутов и методов объекта.

dir(list)
help()

Открывает справку Python. Попробуйте этот пример в локальной среде Python.

help(print)
