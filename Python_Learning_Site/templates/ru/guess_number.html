Игра «Угадай число»

Вы напишете на Python игру, в которой программа загадывает число от 1 до 20, а игрок пытается угадать его за пять попыток.

Перейти к игре ↓

Как устроена игра?

  1. 1. Загадайте число

    Функция randint(1, 20) выбирает случайное целое число от 1 до 20 включительно.

  2. 2. Сравните числа

    С помощью if проверьте, угадал ли игрок загаданное число. Если ответ неверный, подскажите, в какую сторону продолжать поиск.

  3. 3. Посчитайте попытки

    Цикл while продолжается, пока остаются попытки. Каждое новое допустимое число расходует одну попытку. Как только игрок угадает число, игра закончится.

Пример

Допустим, программа загадала 13. Если игрок введёт 8, он получит подсказку «Попробуйте число побольше». Если введёт 17 — «Попробуйте число поменьше». Теперь имеет смысл проверять только числа от 9 до 16.

Попробуйте сыграть

Начните с числа 10. После каждой подсказки выбирайте число ближе к середине оставшегося диапазона. Если ввести недопустимое значение или повторить число, попытка сохранится.

История попыток

    Напишите свою игру

    1. Для начала загадайте постоянное число 13, а ответ игрока получите с помощью input().
    2. Обработайте три случая: число угадано, ответ меньше загаданного, ответ больше загаданного. Используйте if, elif и else. Проверьте программу на числах 8, 17 и 13.
    3. Добавьте цикл while и счётчик попыток. Проверьте, как игра обрабатывает пустую строку, текст и повторный ввод одного и того же числа.
    4. Закончив проверку, замените постоянное число на случайное с помощью randint(1, 20).

    Дополнительное задание. Предложите игроку выбрать сложность. На лёгком уровне дайте четыре попытки, чтобы найти число от 1 до 10, а на сложном — шесть попыток для диапазона от 1 до 50.

    Показать пример программы на Python 
    from random import randint

секрет = randint(1, 20)
попытки = 5
ответы = []
нижняя_граница, верхняя_граница = 1, 20

while попытки > 0:
    print(f"Диапазон поиска: {нижняя_граница}–{верхняя_граница}")
    try:
        ответ = int(input("Введите число от 1 до 20: "))
    except ValueError:
        print("Введите целое число.")
        continue

    if not 1 <= ответ <= 20:
        print("Число должно быть от 1 до 20.")
        continue
    if ответ in ответы:
        print("Вы уже вводили это число. Попробуйте другое.")
        continue

    ответы.append(ответ)
    попытки -= 1

    if ответ == секрет:
        print(f"Верно! Загаданное число — {секрет}.")
        break

    if ответ < секрет:
        нижняя_граница = max(нижняя_граница, ответ + 1)
        print("Попробуйте число побольше.")
    else:
        верхняя_граница = min(верхняя_граница, ответ - 1)
        print("Попробуйте число поменьше.")
    print(f"Осталось попыток: {попытки}")
else:
    print(f"Попытки закончились. Загаданное число — {секрет}.")
