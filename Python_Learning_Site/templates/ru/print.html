Вывод данных с помощью print()

Вы научитесь выводить на экран текст, числа и результаты вычислений, а также задавать разделитель между значениями в одной строке.

Как вывести текст и числа

Текст заключают в кавычки. Числа и арифметические выражения пишут без кавычек. В один вызов print() можно передать несколько значений через запятую.

КодРезультатЧто произойдёт?
print("2 + 3")2 + 3Текст в кавычках выводится без изменений.
print(2 + 3)5Python вычисляет значение выражения.
print("Шаг", 1)Шаг 1Между двумя значениями появится пробел.

Как изменить разделитель и конец строки

sep — разделитель между значениями

По умолчанию значения разделяет один пробел. В этом примере между ними появятся точки.

print("15", "04", "2026", sep=".")
# Результат: 15.04.2026

end — символ в конце строки

Обычно следующий вызов print() начинает новую строку. В примере ниже первый вызов заканчивает вывод пробелом.

print("Обучение", end=" ")
print("началось!")
# Результат: Обучение началось!

Предскажите результат и запустите код

  1. Предскажите, что выведет каждая строка исходной программы. Проверьте свой ответ в редакторе.
  2. Измените sep так, чтобы дата выводилась в формате 15-04-2026.
  3. Используйте два последних вызова print(), чтобы вывести Шаг 1 в одной строке.

Ctrl / ⌘ + Enter — запуск. Tab — отступ. Чтобы выйти из редактора, нажмите Esc, затем Tab.
