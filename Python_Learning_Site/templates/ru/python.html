Что такое Python?

Вы напишете первые команды на Python и увидите результат их работы прямо в браузере.

Как выполняется код на Python?

Программа — это набор команд, которые выполняет компьютер. В примере ниже две команды. Python выполняет их по порядку сверху вниз.

Код

print("Привет, мир!")
print(3 + 4)

Результат

Привет, мир!
7

Первый вызов print() выводит текст в кавычках. Во второй строке Python сначала вычисляет 3 + 4, а затем выводит результат.

Запустите свою первую программу

  1. Нажмите Запустить код и посмотрите на результат.
  2. Во второй команде print() замените текст своим именем. Оставьте имя в кавычках.
  3. Выберите пример Вычисления. Измените числа и попробуйте предсказать новый результат.

Ctrl / ⌘ + Enter — запуск. Tab — отступ. Чтобы выйти из редактора, нажмите Esc, затем Tab.

Для чего используют Python?

Анализ данных

Можно прочитать данные из таблицы, вычислить среднее значение и построить график.

Автоматизация

Программа может взять на себя повторяющуюся работу. Например, переименовать сразу несколько файлов.

Веб-приложения

С помощью Python веб-сервер может обрабатывать запросы и передавать данные на страницу.
