Сортировка данных

Сортировка располагает значения в заданном порядке. На этом уроке вы сравните два способа работы со списком: создание отсортированной копии и сортировку на месте.

▸ Посмотреть видеоурок

Порядок сортировки

1. По возрастанию

От меньшего числа к большему. Такой порядок используется по умолчанию.

sandar.sort()

2. По убыванию

От большего числа к меньшему.

sandar.sort(reverse=True)

Пример. Два варианта порядка для одного списка

Сохраните результат sorted() в отдельной переменной. Параметр reverse=True задаёт сортировку по убыванию. В исходном списке элементы остаются на своих местах.

numbers = [5, 2, 9]
print(sorted(numbers))                # [2, 5, 9]
print(sorted(numbers, reverse=True))  # [9, 5, 2]
print(numbers)                        # [5, 2, 9]

Отсортируйте баллы и сохраните исходный список

Ожидаемый результат [19, 12, 12, 7], на следующей строке — [12, 7, 12, 19]
