Строки

Строка (str) — это последовательность символов. На этом уроке вы получите символ по индексу, выделите часть строки срезом и обработаете введённый текст.

✍️ Как записать строку?

Одинарные и двойные кавычки

"Привет" и 'Привет' обозначают одну и ту же строку. Закрывающая кавычка должна совпадать с открывающей.

Тройные кавычки

"""...""" позволяют записать текст в несколько строк.

Специальные символы

\n — перевод строки, \t — табуляция. Эти последовательности можно вставлять прямо в строку.

a = "Первая строка"
b = 'Вторая строка'
print("Первая\nВторая\tс отступом")

Индексы и срезы

У каждого символа есть индекс. Отсчёт от начала строки начинается с 0, от конца — с −1.

✂️ Срезы (Slices)

Часть строки можно получить срезом [начало:конец]. Как и в range(), правая граница не включается.

s = "Python"
print(s[0:2])    # Py
print(s[2:])     # thon
print(s[:3])     # Pyt
print(s[::-1])   # nohtyP  (в обратном порядке)

Обработка текста

Методы вызываются через точку после строки, например s.strip(). А len(s) — отдельная функция, которой строку передают как аргумент.

Выражение Что делает? Пример
len(s) Возвращает длину строки в символах len("Python") → 6
s.upper() Переводит все буквы в верхний регистр "abc".upper() → ABC
s.lower() Переводит все буквы в нижний регистр "ABC".lower() → abc
s.title() Начинает каждое слово с заглавной буквы "hello world".title() → Hello World
s.strip() Убирает пробельные символы в начале и в конце строки " hi ".strip() → hi
s.replace(a, b) Заменяет вхождения подстроки a на b "cat".replace("c", "b") → bat
s.split() Разбивает строку по пробельным символам и возвращает список слов "a b c".split() → ['a', 'b', 'c']
"-".join(list) Объединяет строки списка в одну строку через заданный разделитель "-".join(["a", "b"]) → a-b
s.find(x) Возвращает индекс первого вхождения x или −1, если x не найден "hello".find("l") → 2
s.count(x) Считает число вхождений x в строку "banana".count("a") → 3
s.startswith(x) Возвращает True, если строка начинается с x "Python".startswith("Py") → True
x in s Проверяет, встречается ли x в строке "th" in "Python" → True

➕ Сложение и умножение строк

print("Привет, " + "мир!")   # Привет, мир!
print("ha" * 3)                # hahaha

Пример. Как привести имя к единой записи

strip() убирает пробелы с обоих концов строки. title() начинает каждое слово с заглавной буквы. Оба метода возвращают новую строку.

name = "  сара  "
print(name.strip().title())  # Сара

⚠️ Частые ошибки

1. Попытка изменить символ строки

Строка — неизменяемый тип данных. Присваивание s[0] = "J" вызовет ошибку TypeError. Чтобы заменить первую букву, создайте новую строку: s = "J" + s[1:].

2. Сложение строки и числа

"Возраст: " + 14 вызовет ошибку. Сначала преобразуйте число в строку: "Возраст: " + str(14).

3. Индекс за пределами строки

Если строка содержит шесть символов, обращение s[10] вызовет ошибку IndexError.
