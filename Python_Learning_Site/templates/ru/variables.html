Переменные и типы данных

Вы научитесь давать значениям имена, обновлять их и различать строки, числа и логические значения.

Как присвоить и обновить значение

Переменная — это имя, которое ссылается на значение. В строке age = 14 знак = присваивает имени age значение справа. Дальше это имя можно использовать в вычислениях или передать в print().

Как меняется значение переменной

age = 14
age = age + 1
print(age)  # 15

Во второй строке Python прибавляет 1 к прежнему значению, а затем присваивает переменной age результат.

Типы данных

У каждого значения в Python есть тип. Его можно узнать с помощью type().

ТипЗначениеПример
intЦелое числоage = 14
strСтрока текстаname = "Аружан"
floatЧисло с плавающей точкойheight = 1.62
boolЛогическое значениеis_ready = True

Имя начинается с буквы или символа _ и пишется без пробелов. Регистр имеет значение: age и Age — разные имена.
