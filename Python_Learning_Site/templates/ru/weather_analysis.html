Анализ данных о погоде

Сохраните температуры за неделю в списке Python. Найдите самую низкую, самую высокую и среднюю температуру за неделю. Посчитайте, сколько дней температура поднималась выше нуля.

Как проанализировать данные?

  1. Запишите в список температуру каждого дня в порядке измерения.
  2. Чтобы найти наименьшее значение, используйте min(), а для наибольшего — max().
  3. Сложите температуры с помощью sum() и разделите сумму на количество дней, которое вернёт len(). Получится средняя температура.
  4. Переберите значения в цикле for. Каждый раз, когда температура выше 0, увеличивайте счётчик на единицу. День с температурой 0 °C в число тёплых не входит.

Пример за три дня

В списке температур [-3, 0, 6] наименьшее значение равно −3 °C, а наибольшее — 6 °C.

Средняя температура равна (-3 + 0 + 6) / 3, то есть 1 °C. Выше нуля температура была один день.
