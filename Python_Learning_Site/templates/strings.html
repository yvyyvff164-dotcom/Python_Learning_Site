📝 Мәтіндік жолдар (Strings)

Жол (string) — бұл тырнақшаға алынған әріптер, сандар мен таңбалар тізбегі. Аты-жөнді, мекенжайды, хабарламаны — кез келген мәтінді Python-да жол ретінде сақтаймыз. Жолдың типі — str.

✍️ Жолды қалай жазамыз?

Бір немесе қос тырнақша

"Сәлем" және 'Сәлем' — екеуі де бірдей жұмыс істейді. Негізгісі — ашылған және жабылған тырнақша бірдей болуы.

Үш тырнақша

"""...""" ішіне бірнеше жолдан тұратын ұзын мәтін жазуға болады.

Арнайы таңбалар

\n — жаңа жол, \t — табуляция (шегініс). Олар жол ішінде жазылады.

a = "Бірінші жол"
b = 'Екінші жол'
print("Бірінші\nЕкінші\tшегінісімен")

🔢 Индекстер: әр әріптің өз орны бар

Жол — бұл әріптер тізбегі. Әр әріптің нөмірі (индексі) бар. Санау 0-ден басталады, ал соңынан санағанда -1-ден басталады.

print(s[-1])   # n

✂️ Кесінділер (Slices)

Жолдың бір бөлігін алу үшін [бастапқы:соңғы] жазылады. Соңғы индекс кірмейді, дәл range() сияқты.

s = "Python"
print(s[0:2])    # Py
print(s[2:])     # thon
print(s[:3])     # Pyt
print(s[::-1])   # nohtyP  (кері бұру)

🛠 Жолдармен жұмыс істейтін әдістер

Әдіс жолдан кейін нүкте қойып шақырылады: жол.әдіс().

Әдіс Не істейді? Мысал
len(s) Жолдың ұзындығын (таңба санын) қайтарады len("Python") → 6
s.upper() Барлық әріпті бас әріпке айналдырады "abc".upper() → ABC
s.lower() Барлық әріпті кіші әріпке айналдырады "ABC".lower() → abc
s.title() Әр сөздің бірінші әрпін бас әріп етеді "hello world".title() → Hello World
s.strip() Жолдың басы мен соңындағы бос орындарды өшіреді " hi ".strip() → hi
s.replace(a, b) a бөлігін b-ға ауыстырады "cat".replace("c", "b") → bat
s.split() Жолды сөздерге бөліп, тізім жасайды "a b c".split() → ['a', 'b', 'c']
"-".join(list) Тізім элементтерін бір жолға біріктіреді "-".join(["a", "b"]) → a-b
s.find(x) x-тің бірінші орнын табады (жоқ болса -1) "hello".find("l") → 2
s.count(x) x қанша рет кездесетінін санайды "banana".count("a") → 3
s.startswith(x) Жол x-пен басталса True қайтарады "Python".startswith("Py") → True
x in s Жолдың ішінде x бар ма, соны тексереді "th" in "Python" → True

➕ Жолдарды біріктіру және көбейту

print("Сәлем, " + "Әлем!")   # Сәлем, Әлем!
print("ha" * 3)                # hahaha

⚠️ Жиі кездесетін қателер

1. Жолды өзгертуге болмайды

Жол — өзгермейтін (immutable) тип. s[0] = "J" деп жазсаң, Python TypeError қатесін береді. Жаңа жол жасау керек: s = "J" + s[1:].

2. Жол мен санды қосуға болмайды

"Жасы: " + 14 қате береді. Санды алдымен жолға айналдыр: "Жасы: " + str(14).

3. Индекс шектен шығып кетті

6 таңбалы жолда s[10] деп сұрасаң, Python IndexError қатесін шығарады.
