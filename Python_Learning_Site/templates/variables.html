Айнымалылар және деректер типтері

Мәнге атау беруді, оны жаңартуды және мәтіннің, санның, логикалық мәннің айырмасын үйренесіз.

Мәнге атау беру және оны жаңарту

Айнымалы — мәнге сілтейтін атау. age = 14 жолындағы = белгісі оң жақтағы мәнді age атауына меншіктейді. Кейін осы атауды есептеуде немесе print() ішінде қолдануға болады.

Мысал: мән қалай өзгереді?

age = 14
age = age + 1
print(age)  # 15

Екінші жол алдымен бұрынғы мәнге 1 қосады. Содан кейін age атауына жаңа мән беріледі.

Деректер типтері

Python типті мәнге қарай анықтайды. type() функциясы сол мәннің типін көрсетеді.

ТипМағынасыМысал
intБүтін санage = 14
strМәтіндік жолname = "Аружан"
floatЖылжымалы нүктелі санheight = 1.62
boolЛогикалық мәнis_ready = True

Атау әріптен немесе _ таңбасынан басталады және бос орынсыз жазылады. Бас және кіші әріптер ажыратылады, сондықтан age пен Age — екі бөлек атау.

Оқушы туралы деректерді өзгертіңіз

  1. name мен city мәндерін өзіңізге сай өзгертіңіз.
  2. age мәнін 16 етіп қойыңыз. Бес жылдан кейінгі жасты тексеріңіз.
  3. age мәнін уақытша "16" деп жазыңыз. Нәтижені қарап, одан кейін тырнақшаларды алып тастаңыз.

Ctrl / ⌘ + Enter — іске қосу. Tab — шегініс. Редактордан шығу үшін Esc, содан кейін Tab басыңыз.

▸ Не себепті қате шығады?

16 — бүтін сан, ал "16" — мәтін. Python мәтінге 5 санын тікелей қоса алмайды. Егер мәтінде бүтін сан жазылса, int("16") + 5 өрнегінің нәтижесі 21 болады.
