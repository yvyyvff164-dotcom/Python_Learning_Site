📦 Айнымалылар (Variables) және деректер типтері

Бұл сабақта сен Python тілінде ақпаратты қалай сақтауға, оларды түрлеріне қарай ажыратуға және нақты кодпен жұмыс істеуге үйренесің.

Айнымалы — бұл компьютердің жадында мәліметтерді сақтауға арналған атаулы "қорапша". Біз бұл қорапшаға сан, мәтін немесе басқа да маңызды ақпаратты сақтап, кейін оны бағдарлама ішінде аты арқылы оңай шақыра аламыз.

📊 Негізгі деректер типтері

Python-да айнымалының типін қолмен көрсету қажет емес, ол мәннің түріне қарай өзі автоматты түрде анықтайды:

Тип аты Мағынасы мен сипаттамасы Кодтағы мысалы
int Бүтін сандар (теріс және оң сандар) age = 15
str Мәтіндік жолдар (тырнақшаға алынады) name = "Sanzhar"
float Ондық сандар (нүкте арқылы жазылады) pi = 3.14
bool Логикалық мән (True немесе False) is_active = True
