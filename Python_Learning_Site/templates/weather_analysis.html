Ауа райы деректерін талдау

Бір аптадағы температураларды Python тізіміне сақтап, ең суық және ең жылы күннің температурасын, аптадағы орташа мәнді және жылы күндер санын есептеңіз.

Апталық деректерге өту ↓

Талдауды қалай жүргіземіз?

  1. Әр күннің температурасын өлшенген ретімен тізімге жазыңыз.
  2. Ең кіші мәнді min(), ең үлкен мәнді max() арқылы табыңыз.
  3. Орташа мәнді табу үшін температуралардың қосындысын sum() арқылы есептеп, күндер санына len() арқылы бөліңіз.
  4. Күндерді for циклімен қарап шығыңыз. Температура 0-ден жоғары болған сайын есептегішті біреуге арттырыңыз. 0 °C жылы күнге жатпайды.

Үш күндік мысал

Температуралар [-3, 0, 6] болса, ең төменгі мән −3 °C, ең жоғарғы мән 6 °C.

Орташа мән (-3 + 0 + 6) / 3 арқылы шығады, яғни 1 °C. Нөлден жоғары температура бір күнде байқалды.

Апта деректерін талдаңыз

Бір аптаны таңдап, жеті күннің көрсеткіштерін талдаңыз. Нәтижелеріңізді тексерген соң, Python кодымен салыстырыңыз.

    Есептеу нәтижелері

    Орташа мәнді ондық үлеске дейін дөңгелектеңіз. Мысалы, 2,43 → 2,4.

    Python шешімін көру

    Кодты іске қосып, нәтижені өз жауабыңызбен салыстырыңыз. Содан кейін тізімдегі бір температураны өзгертіп, қай нәтиже өзгеретінін тексеріңіз.

    Қосымша тапсырма. Нөлден төмен температура тіркелген күндердің санын да шығарыңыз.
